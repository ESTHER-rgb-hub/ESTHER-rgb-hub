## PROJETOS ACADEMICOS:

📌 **Descrição:**  
Projeto acadêmico desenvolvido na disciplina de **Design Profissional em Ciência da Computação** 
com o objetivo de criar uma plataforma interativa para profissionais de TI apresentarem suas habilidades, 
experiências e projetos, unificando identidade visual e presença online.


---


## 🛠 Tecnologias Utilizadas
[HTML5, CSS3, JavaScript, Bootstrap] 
[Node.js, Express.js]
[Banco de Dados]
[GitHub, Git e Linkedin]

---

## 💡 Desafio
Muitos estudantes e profissionais de TI têm dificuldade em manter uma presença online consistente e centralizada, resultando em perfis desatualizados ou fragmentados.  
O desafio foi criar uma solução que facilitasse a integração de todas as informações em um só lugar, com design profissional e adaptável para diferentes dispositivos.

---

## 🛠 Solução
1. Definir a identidade visual e a navegação intuitiva.  
2. Responsivo com Bootstrap e CSS customizado.  
3. Integração com APIs do LinkedIn e GitHub para importação automática de informações.  
4. Sistema de autenticação.
5. Hospedagem em nuvem.

---

## 📈 Resultados
- Exibição de projetos e informações profissionais.  
- Integração automática com GitHub para exibir repositórios mais relevantes.  
- Possibilidade de exportar o portfólio em PDF para candidatura em vagas.
